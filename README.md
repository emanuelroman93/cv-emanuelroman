# TP 1 - CURRICULUM

Este proyecto consiste en la realización del primer trabajo práctico para la materia Computacion 3. Al ser mi primera aproximación al diseño web, resulto un desafio pero al mismo tiempo esta resultando una experiencia muy entretenida para ir adquiriendo estas herramientas.
El diseño del curriculum esta por un lado enmarcado dentro de mis limitaciones con html y css pero tambien inspirado en una estética que me gusta y en la web de mi emprendimiento. Aunque ahi resulta mucho mas fácil la customizacion porque no hay que codear :D
( https://borisstore.empretienda.com.ar/ ).

## Especificaciones técnicas
- Tamaño de pantalla 3200x2000px (Lenovo Yoga Pro i9)
- Editor de código: Visual Studio Code

## Desafios
- Ajustar el diseño para que siga manteniendo esa estética vintage pero de una manera mas dinámica.
- Ajustar los párrafos para que no tengan ese salto de linea tan horrible.
- Agregar elementos con movimiento.
